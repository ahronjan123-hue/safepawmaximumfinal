# SafePaw

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies with `npm install`.
2. Start the app with `npm run dev`.
3. Open the local URL printed in the terminal (by default, `http://localhost:3000`).

The app runs locally without a hosted database or Vercel. App data is stored in
the browser's local storage; veterinarian applications are held in server memory
and are cleared when the local server restarts.
